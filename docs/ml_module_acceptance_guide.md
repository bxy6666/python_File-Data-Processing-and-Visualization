# 数据分析与机器学习模块验收答辩准备文档

## 1. 模块定位

我负责的是 DataFlow 项目中的“数据分析与机器学习”模块，核心目标是在数据完成上传和清洗之后，对清洗后的数据执行 K-Means 聚类分析，并把分析结果保存下来，供后续图表可视化和结果导出模块继续使用。

在整个系统流程中，我的模块位于第三步：

```text
上传数据 -> 数据清洗 -> K-Means 分析 -> 图表可视化 -> 结果导出
```

对应的后端接口是：

```text
POST /api/analyze
```

对应的核心代码文件是：

```text
app/utils/ml_utils.py
```

路由层已经在 `app/routes.py` 中完成了参数接收、前置状态检查、统一 JSON 响应和结果保存。我的主要工作集中在 `run_kmeans(dataframe, k)` 这个函数中。

## 2. 我完成的主要工作

本模块目前完成了以下内容：

1. 实现 K-Means 聚类分析函数 `run_kmeans(dataframe, k)`。
2. 自动从清洗后的 DataFrame 中选择数值型字段。
3. 自动过滤不能参与聚类的缺失样本。
4. 使用 `StandardScaler` 对数值特征进行标准化，避免不同量纲影响聚类结果。
5. 使用 scikit-learn 的 `KMeans` 执行聚类。
6. 返回聚类结果、聚类中心、每条数据所属类别、样本统计和聚类惯性值。
7. 补充 `pandas` 和 `scikit-learn` 依赖。
8. 编写了独立单元测试，覆盖正常流程和异常输入。

## 3. 模块输入与输出

### 3.1 输入

函数入口：

```python
run_kmeans(dataframe, k)
```

参数说明：

- `dataframe`：清洗模块返回的 Pandas DataFrame。
- `k`：聚类数量，来自前端输入，路由层会先做基础校验。

示例请求：

```json
{
  "method": "kmeans",
  "k": 3
}
```

### 3.2 输出

函数返回结构符合项目约定：

```python
{
    "result": analysis_result,
    "summary": summary
}
```

其中 `summary` 会直接返回给前端展示，`result` 会保存为 `analysis_result`，供后续可视化和导出使用。

主要字段包括：

- `method`：分析方法，目前是 `kmeans`。
- `k`：聚类数量。
- `columns`：实际参与聚类的数值列。
- `rows_used`：实际参与聚类的样本数。
- `rows_skipped`：因为缺失值等原因跳过的样本数。
- `inertia`：K-Means 的惯性值，用于反映样本到簇中心的距离总和。
- `clusters`：每个聚类的编号、样本数量和中心点。
- `labels`：每条数据对应的聚类标签。

示例返回摘要：

```json
{

  "rows_used": 6,

  "inertia": 0.143677,

    {
      "cluster": 0,
      "count": 3,
```

## 4. 算法实现流程

本模块的 K-Means 分析过程可以分为 6 步。

### 4.1 加载依赖

模块内部通过 `_load_sklearn()` 加载：

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
```

如果环境中没有安装 scikit-learn，会抛出清晰的错误提示：

```text
缺少 scikit-learn 依赖，请先运行 pip install -r requirements.txt
```

这样做的好处是：项目不会在启动时因为缺少机器学习依赖直接崩溃，而是在真正调用分析功能时给出明确提示。

### 4.2 校验 k 值

模块会把 `k` 转为整数，并进行以下校验：

- `k` 必须是数字。
- `k` 不能小于 2。
- `k` 不能大于可用样本数。

这些校验可以避免 K-Means 在非法参数下运行失败。

### 4.3 选择数值列

K-Means 只能处理数值特征，所以模块通过：

```python
dataframe.select_dtypes(include=["number"])
```

自动选择数值列。

如果数据中没有数值列，则返回错误：

```text
数据中没有可用于聚类的数值列
```

这样可以避免用户上传全是文本的数据时，算法强行运行导致错误。

### 4.4 处理缺失样本

对于参与聚类的数值列，如果某一行存在缺失值，模块会跳过这一行：

```python
numeric_dataframe.dropna(axis=0, how="any")
```

同时记录跳过的行数，返回到 `rows_skipped` 中。

这样做的理由是：清洗模块理论上已经处理缺失值，但机器学习模块仍然做一次防御性处理，保证算法输入稳定。

### 4.5 特征标准化

模块使用：

```python
StandardScaler()
```

对数值特征进行标准化。

标准化的原因是不同字段的量纲可能差异很大。例如：

- 销售额可能是几千或几万。
- 利润率可能是 0 到 1 之间。

如果不标准化，数值范围大的字段会主导距离计算，影响聚类效果。

### 4.6 执行 K-Means 聚类

模块使用：

```python
KMeans(n_clusters=k, random_state=42, n_init=10)
```

其中：

- `n_clusters=k`：聚类数量来自用户输入。
- `random_state=42`：保证每次运行结果稳定，方便验收和测试。
- `n_init=10`：多次初始化，选择较好的聚类结果。

聚类完成后，模块会把标准化空间中的聚类中心反向转换回原始数值尺度，方便用户理解。

## 5. 为什么选择 K-Means

本项目是课程实验中的交互式数据分析系统，K-Means 比较适合作为第一版机器学习分析功能，原因如下：

1. 算法经典，容易解释。
2. 适合对数值型表格数据做初步分组。
3. 不需要标签数据，属于无监督学习，更适合用户上传任意数据集后的探索分析。
4. 结果可以自然用于可视化，例如散点图中用不同颜色展示不同聚类。
5. scikit-learn 提供成熟实现，稳定可靠，适合课程项目使用。

## 9. 答辩常见问题准备

### 问题 1：为什么要先选择数值列？

K-Means 是基于距离计算的算法，只能处理数值型特征。文本字段无法直接参与距离计算，所以模块会自动筛选数值列，避免用户上传包含文本字段的数据时程序报错。

### 问题 2：为什么要做标准化？

因为不同字段的数值范围可能差异很大。如果不标准化，数值范围大的字段会在距离计算中占主导，导致聚类结果偏向某些字段。标准化后，每个字段会在相近尺度下参与聚类，结果更合理。

### 问题 3：为什么使用 K-Means？

K-Means 是经典的无监督聚类算法，不需要提前准备标签数据，适合用户上传任意表格数据后的探索分析。它的结果也比较容易解释，可以自然地和后续可视化模块结合。

### 问题 4：如果用户输入的 k 不合理怎么办？

模块做了参数校验。如果 `k` 不是数字、小于 2，或者大于可用样本数，都会抛出明确错误。路由层会把错误包装成统一 JSON 响应返回给前端。

### 问题 5：如果数据里有缺失值怎么办？

理论上缺失值应该由清洗模块先处理。但为了保证机器学习模块本身稳定，我在模块里也做了防御性处理：如果参与聚类的数值列中某一行存在缺失值，就跳过该行，并把跳过数量记录到 `rows_skipped` 中。

### 问题 6：聚类结果怎么给后续模块使用？

模块返回的 `labels` 表示每条数据属于哪个 cluster，`clusters` 表示每类的样本数量和中心点。这些信息可以用于可视化，比如散点图按 cluster 上色，柱状图展示各类样本数量，或者在页面上展示各类特征中心。

### 问题 7：怎么保证结果稳定？

K-Means 本身有随机初始化过程，所以我设置了 `random_state=42`。这样同一份数据、同一个 k 值，多次运行可以得到稳定结果，方便测试和验收。

### 问题 8：你做了哪些测试？

我写了独立单元测试，覆盖正常运行和异常情况。正常情况包括返回结构、聚类中心、聚类数量、标签结果；异常情况包括非法 k、没有数值列、有效样本不足、非 DataFrame 输入和缺少依赖等。当前 11 个测试全部通过。
